# 🎬 FilmLy

FilmLy is a full-stack application for browsing movies and series, managing personal watchlists, and receiving personalized recommendations.

---

## 📁 Project Structure

```
FilmLy/
├── backend/    — Spring Boot REST API
└── frontend/   — React + TypeScript web application
```

| Part | README |
|------|--------|
| 🖥 Backend | [backend/README.md](backend/README.md) |
| 🌐 Frontend | [frontend/README.md](frontend/README.md) |

---

## ✨ Key Features

- 🎬 Browse popular, trending, recent and upcoming movies & series from TMDB
- 🔍 Search and discover content by title, genre, rating and release date
- ❤️ Like / dislike content
- 📋 Personal watchlist with watched/unwatched tracking
- ⭐ Rate and review movies & series
- 🤖 Personalized recommendations based on favorite genres, vote quality, release date and popularity
- 🔐 JWT authentication with email & password change verification flow
